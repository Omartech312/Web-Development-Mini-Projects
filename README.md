# Web-Development-Mini-Projects
A collection of mini projects created as I review HTML, CSS, JavaScript, TypeScript, and React

## Counter
This project focuses on storing elements by ID into constants to then check if buttons are clicked to trigger a simple arithmetic change to the page's counter.

## Display_Products
This project uses JavaScript to create a product object containing: name, price, quantity, unit and an image to create a product card, similar to small stores displaying their catalog of products.

## REACT/ColorPicker
This project uses useState() and onChange() to automatically change the background color of the website upon detecting a input change
